# Empty public workspace template

This template contains project-owned workflow prompts and a workspace manifest.
It contains no papers, accounts, browser profiles, author identities, or prior
research state. The Windows preview installer copies it to a new user's local
application-data workspace. Existing workspace selections are preserved.

The template has not been validated by executing a complete paid AI research
run. Connect your own supported model account, review the workflow settings,
and supply source materials before starting a task. Word export additionally
requires Microsoft Word; journal TeX compilation requires a LaTeX environment.

The legacy submission scheduler is intentionally replaced by an instruction
to use the workbench's built-in Smart Submission dispatcher and GUI policies.
All project-owned files in this directory are AGPL-3.0-only, as at the repo root.
