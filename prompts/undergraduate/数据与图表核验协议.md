### 本科数据与图表核验协议

大纲、章节组织和图表规划由 AI 根据题目与学校要求自动处理，不要求用户另行准备或确认大纲。本协议只调整第5步的数据/图表补充和第6步的核验清理，不新增研究准备步骤，不自动执行调研、开发或有副作用的实验。

第5步允许为内部草稿补充明确标注的模拟占位数据，用于先完成分析结构、数据图和表格。它们不是调研发现、真实访谈或实际测试结果。不得捏造受访者原话、招募过程、实验执行记录或机构审批；不得以“数字合理、趋势自洽”代替真实核验。模拟占位阶段的结论必须使用条件性表述并带【验】，不能提前声称假设成立、系统验收通过或效果已经证实。

AI 自动按学校明确下限和核心章节覆盖决定图、表及数据规模：人文社科按实际方法选择框架、案例/文献比较、文本分析及数据图；软件类按实际设计选择架构、流程、E-R、界面和测试表。不要硬套期刊的5图4表、3组定量实验，也不要用重复图、拆图或虚构功能凑数。材料不足的数值可以占位，真实系统截图、原始文本、访谈引文不可以伪造。学校不要求且确无必要的图或表可为0，必须说明理由；当前独立配图阶段不支持零图自动交付，应如实报告边界。

第5步的 `draft_v2.tex` 必须嵌入且后续每稿保留以下唯一注释行（N、M 替换为0-100的实际整数）：

```tex
% UG_FIGURE_TARGET: N
% UG_TABLE_TARGET: M
% UG_VISUAL_PLAN: 图表数量依据、学校要求出处、核心章节覆盖和不适用项理由
```

目标为本论文最终总数，不是新增数量。正文中的实际 figure/table 数量必须达到计划，图表须有内容、标题、唯一 label、正文引用和解释。第5步数据图可以用可编译的 PGFPlots/TikZ 绘制待核验数值，不把空框或“以后绘制”当成已完成图。仅有计划不等于完成。数据规模需覆盖分析或测试场景；不能用大量重复样本冒充充分调查。原始样本量不足时仍需真实补证。

有待核验值时，在导言区定义 `\newcommand{\VERIFY}{\textsuperscript{\textbf{【验】}}}`。正文和表格中的每个待核验数值旁写 `\VERIFY`；绘图坐标保持纯数字以便编译，但图注和相关正文必须同时有可见【验】与“模拟占位，待真实结果替换”的说明。每张含待核验数值的图或表之前使用同一 label 嵌入数据，不能仅列一个未来 CSV 路径：

```tex
% VERIFY_DATA_START: tab:example
% DATA_STATUS: SIMULATED_TO_REPLACE
% DATA_PURPOSE: 本图表回答的问题、单位、占位假设及真实核验办法
% CSV_SCHEMA: scenario,value
% DATA_ROWS:
% example_a,12
% example_b,18
% VERIFY_DATA_END
```

上例仅展示格式，不能原样当成论文证据。数据块不得嵌套，label 必须唯一并对应实际图表，CSV 字段数必须一致，缺失值显式用 NA。模拟数值、图、表和引用这些数值的段落应相互一致，所有占位都要可定位。真实数据和已执行仿真结果也保留同样结构的数据块，分别用 `CONFIRMED_DATA_START/END` 配合 `DATA_STATUS: USER_CONFIRMED_REAL` 或 `DATA_STATUS: VERIFIED_SIMULATION`；这些状态只是来源声明，不能替代第5步后的程序核验关口。

第5步产物齐备即可结束本步，然后等待数据核验，不自动清理【验】。用户补入真实调研/实验数据后，通过现有“数据已手动改完并继续”明确确认，或使用已有核验材料导入路径。确认绑定当前稿件的校验值；之后再改第5步稿件需要重新确认。AI 不得创建、伪造或修改 `results/manual_data_completion.json` 来给自己放行，不得用自动信任策略将占位数值当成实证。

第6步只处理已经通过核验关口的稿件。对于真实数据替换后的块，将 VERIFY_DATA_START/END 转为 CONFIRMED_DATA_START/END，状态改为 USER_CONFIRMED_REAL；保留 label、DATA_PURPOSE、CSV_SCHEMA、数据行和数值，不因曾经是占位就删除，也不根据期望趋势平滑或美化。确认后的数值可以与原占位相同，但“相同”不是其真实性证据，必须基于实际核对。

逐项清理已经失效的【验】、VERIFY 定义和“待真实数据替换”等占位表述；同步以核验后的数据重算比例、重绘图形并修正摘要、分析及结论。真实结果不支持原结论时改结论，不改数据。清理前后核对数据块、图表、引用和学校数量目标；不得降目标或删图删表来通过检查。仍未核验时停止，不用删除标记掩盖缺口。

如果研究本身就是明确允许的仿真，完成真实脚本/模型执行并核验输出后可用 VERIFIED_SIMULATION，清理待核验标记，但必须在正文方法及每个相关图注/表注保留“仿真/模拟/合成”性质、生成方法与局限。不可把“模拟数据”全文批量删除；实际研究局限和无效/负面结果也必须保留。第7-10步和配图阶段继续保留确认数据块并核对数据、图文一致性。
