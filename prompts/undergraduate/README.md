# 本科论文提示词方案

本目录保存本科写作及配套画图的出厂提示词。GUI 0.12.0b9 增加最终 Word 生成、实际排版渲染与逐页验收。保留第5步【验】占位与第6步核验清理；写作与配图随论文类型一起绑定，原期刊提示词文件不被覆盖。

公共规则见 [数据与图表核验协议](数据与图表核验协议.md)。软件自动将其加入本科逐步提示词快照；手动使用文件时也需一并提供。AI 自动处理大纲，无新增大纲确认。第5步补图表与带【验】的模拟占位，第6步必须先明确确认已用真实调研/实验材料替换核对，或通过核验材料导入；然后清理标记、保留确认数据与仿真性质说明。详见 [b8 说明](../../GUI-0.12.0b8-说明.md)。

- [人文社科版](人文社科版.md)：文献研究、文本分析、案例研究、问卷和访谈。
- [计算机软件版](计算机软件版.md)：基于真实软件项目的需求、设计、实现、测试及论文说明。
- [人文社科配图](画图-人文社科版.md)：研究框架、分析流程和基于真实证据的数据图。
- [计算机软件配图](画图-计算机软件版.md)：系统架构、流程、E-R/UML 和真实测试图。

## 在软件里切换

1. 使用 `UnifiedPaperWorkbench-0.12.0b8.exe`，在总览或写作页点击“新建毕业论文”。无需先修改全局提示词设置。未编辑的旧出厂本科方案对新论文自动刷新；自定义方案不覆盖，已有论文快照不变。
2. 选择本科方向，填写已经确定的题目。界面同步显示配图方向，可点击“查看配图方案”。
3. 粘贴学校要求，或选择资料用途后添加文件、文件夹或 ZIP；核对附件清单、提取状态与预览。学校最低参考文献数只填明确规定的值。
4. 点击“创建并开始第一步”。导入本身不调用 AI；此按钮会启动写作任务并消耗模型额度。已有期刊方案切换入口仍保留。

资料副本保存在当前写作工作区的 `materials/undergraduate/<随机批次>/`，标题、附件用途、文件及文字校验值写入本论文快照；改变外部原件不会改变已经导入的副本。移除或取消只取消本次关联，副本暂时保留在本地，避免误删其他任务引用的文件。程序不上传资料到商业控制面，但写作/画图模型运行时会按任务读取必要材料。

PDF 只提取文字层，图片/扫描件未 OCR；DOCX 只提取文字，不保证还原字体、页边距和模板布局；旧 DOC 需转 DOCX/PDF。导入和文字提取不代表格式合格、材料真实性核验或学术验收。文件限制见界面；只支持 ZIP，不递归展开嵌套压缩包，不执行导入的代码/宏，已知凭据配置和程序文件会跳过。不要把个人目录、凭据或敏感原件作为资料包导入。

本科画图共三步：规范与配图需求、逐图规划、生成并整合。新任务创建时固定对应画图提示词、默认模型配置及同一份学校材料；进入画图时按该快照执行。b6 已有本科论文首次进入画图时补上对应类型的配图快照。设置中的画图页可预览两套本科配图文本；下方原期刊模型/步骤编辑器仍是期刊配置，不会回写已有本科论文。编辑出厂文件只影响以后新建/首次绑定的任务。

需要画图时进入“图表与插图”阶段启动这篇论文，或使用既有的写作到画图交接。这里不承诺自动启动下一阶段；一旦进入画图，将自动匹配论文方案，不需要手动切换。完成配图后本科论文止于毕业论文交付，不自动选刊、投稿。

方案只作用于之后新建的论文。已排队或运行中的论文保存独立的方案、输入和逐步提示词快照，切换或编辑设置不会改变它们。再次选回某方案，会恢复该方案上次的自定义内容；“恢复默认流程”恢复当前方案的出厂十步。每步“提示词”按钮可查看、编辑本科提示词，保存会建立新版本。不要在旧 EXE 中用粘贴覆盖原期刊内置提示词的方法代替方案切换。

## 手动使用文本

每份文件包含“通用要求”和对应现有十步的任务。手动使用时，把通用要求、当前 Step 和本次实际材料一起交给 AI；也可提供全文并明确指定当前 Step。不要要求一次执行全部十步。无需更换模型。

第一步由你提供论文题目和学校要求、格式模板（文字、文档或截图均可）。AI 不再选题，而是保留题目原文、整理学校要求和待确认项，写入本论文的第一步产物；后续九步持续沿用，从初稿开始按学校要求组织，不等终稿才检查格式。未提供或无法辨认的内容不自行编造，要求冲突时才集中向你确认。

材料可以直接通过对话提供，不要求另建资料库。例如：“执行人文社科版 Step 1。题目：《……》。附件是学校论文格式要求，请保留题目，整理后续写作需遵循的要求。”

文件保留原十步的产物路径命名。新 GUI 的步骤名称随方案切换；后台文件名仍沿用兼容命名。

## 校验与交付边界

原期刊方案仍使用原来的固定提示词校验。新本科方案从自己的不可变论文快照读取当前一步，不替换 `stages/writing/prompts`，并使用独立本科输出检查，不套用 8 个侦察网址、50 条文献、5 图 4 表或机器学习审稿标题。

本科检查仍要求有效来源记录与 BibTeX 对应、正文引用属于本论文文献库、稿件结构与文件完整；第六步和交接稿不能残留未解决的证据占位。新版第5步检查模型依据学校要求制定的图表目标、数据块与可见标记，第6步检查绑定当前稿件的数据核验及确认数据保留。填写的学校最低文献数参加程序检查；学校要求理解、来源真实性与学术质量仍需核对，不能把自动文件检查当成学校验收。

写作10步使用中文 LaTeX 中间稿，第10步名为“写作定稿与配图交接”。配图第3步必须生成可编辑 Word、通过本机 Microsoft Word 更新目录页码并导出预览，逐页与逐项学校要求复核后才完成。正式文件在画图工作区 papers/<ID>/delivery/ 下，软件提供“打开 Word 正式稿”和“打开 Word 排版预览”。没有 Word 排版引擎、缺少 DOCX、预览或复核记录，或原稿/图/格式/Word 文件变化时均不算交付完成。一般学校样式由 word_layout.json 配置，复杂封面与分节须在 Word 文件内落实，再用 --render-existing 重新渲染验收；不能只继承样式就宣称模板完全符合。材料不足时保留缺口，不编造数据、图表或完成标记。

## 核对范围

两套方案均有不调用真实模型的十步测试，以及版本隔离、学校文献下限和缺失证据阻断测试。界面用隔离数据验证；这些验证不等于真实论文质量评测，不代表导师或学校验收。

编写参考 [OpenAI 官方提示词指南](https://developers.openai.com/api/docs/guides/prompt-engineering)：用清晰的分节区分任务指令、上下文、输出要求和停止条件。学科要求根据本项目用途单独编写，不是官方学科模板。
