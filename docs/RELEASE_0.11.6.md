# 0.11.6 发布记录

## 目标

在不修改写作、图表与插图、选刊作者阶段内部提示词的前提下，完成主要功能按钮核验，并用正式工作区并行跑通两篇论文从写作到智能投稿的完整生产流程。

## 本版修复

- 智能投稿显式启动时会清除陈旧暂停标记，避免任务已入队但 SDK 队列不执行。
- 增加最终投稿页面的只读恢复：只有项目持有的同一论文、同一路线、同一页面和稳定最终控件同时成立时，才会恢复为可继续状态。
- Wiley 联合账号从作者域切换到投稿域后，程序可在旧授权从未被领取或使用时重新签发绑定当前会话的单次授权。
- 支持 Wiley 在最终 review URL 不跳转、只替换页面成功内容的行为；成功标记例外严格限制在最终 review 页面，普通 draft 页面不能被误认成投稿成功。
- 作者资料归一化继续兼容旧结构：空作者称谓不再产生额外字段，非空称谓仍会保留。
- 投稿监控因登录或验证暂缓时，会正确移出在线执行队列，不再显示为残留运行任务。
- 修复自定义写作尾部 Step 的局部变量初始化问题，不改变用户保存的自定义提示词。
