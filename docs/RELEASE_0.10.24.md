# 0.10.24：品牌视觉与高 DPI 工作台

发布日期：2026-07-21

## 本版目标

0.10.24 在 0.10.23 已建立的专业工作台结构上继续做视觉成熟度治理。目标不是另建前端或改变流程，而是在保留现有 Tk/ttk 桌面架构的前提下，让五个阶段形成统一、可识别、适合长期使用的产品界面。

本版没有修改写作、画图、选刊作者或智能投稿的阶段内部提示词，没有改变业务状态机、SDK 调度、产物契约、论文工作区或现有任务数据。

## 与 0.10.23 的主要区别

### 独立品牌与应用图标

- 新增原创品牌标识：以论文页、工作流连线和三个协同节点表达“论文智能体编排”；
- 提供 24、32、40、48、64、96、128、256 像素的透明 PNG，以及 Windows 多尺寸 `app_icon.ico`；
- 品牌标识用于应用头部、空状态和 Windows EXE，标题栏、任务栏与产品界面不再依赖默认 Tk 图标；
- 资源统一位于 `unified_paper_orchestrator/ui/assets/`，打包时由 PyInstaller 显式携带。

### 统一图标语言和操作层级

- 增加一套代码原生的线性操作图标，覆盖刷新、新建、运行、暂停、设置、账号、更多、紧急停止及五个主阶段；
- 主动作使用蓝色，危险动作使用红色，暂停使用警示色，设置与低频操作保持中性；
- 写作、画图、选刊作者和投稿中心继续保留各自原有动作语义，只调整视觉层级与可读性。

### 产品化导航与投稿通道

- 主导航改为无边框产品导航，并使用蓝色下划线显示当前阶段；
- 原生 Notebook 继续作为内部页面容器，但不再暴露厚重的系统页签外观；
- 投稿中心的“稳定投稿 / 智能投稿”改为带用途说明的通道卡片，明确默认生产通道与试运行通道的差异；
- 切换通道不会改变论文投稿路线、账号资料或既有状态。

### 状态、卡片与详情层级

- 总览指标增加统一图标、色彩和比例说明；
- 普通、运行中和已完成任务不再大面积整行铺色，整行背景只用于阻塞、失败、排队和人工越级等异常或注意状态；
- 空详情使用品牌化空状态；
- 详情区域采用标题、状态 Badge、章节标记、下一步和技术层分级，默认阅读层不再直接堆叠原始日志；
- 写作页将 Token 超限、产物契约失败和不确定 Turn 等底层错误转换为可执行的中文摘要，完整诊断仍保留在技术信息中。

### 高 DPI 与小窗口空间利用

- 表格列宽、行高、左右分栏和详情宽度按窗口宽度重新分配；
- 论文编号在窄窗口下采用保留身份前缀的紧凑显示，完整编号与技术信息仍可查看；
- 小窗口会收纳低频动作和高密度概览，优先保留主操作、任务列表和下一步；
- 宽屏继续扩展论文列表与结构化详情，不通过固定像素强占空白。

### 无可见命令行窗口

- 正式 EXE 继续使用隐藏控制台的启动模式；
- 本版构建后的实机启动只显示唯一产品窗口，没有出现可见 CMD 或 PowerShell 窗口；
- PyInstaller 单文件父进程与隐藏控制台宿主属于内部运行实现，不会形成用户可见窗口。

## 新增或重点调整的模块

- `unified_paper_orchestrator/ui/visual_assets.py`：资源解析、窗口图标、品牌图和统一操作图标；
- `unified_paper_orchestrator/ui/assets/`：品牌与 Windows 图标资源；
- `unified_paper_orchestrator/ui/theme.py`：字体、按钮、导航、卡片、表格和高 DPI 主题；
- `unified_paper_orchestrator/ui/detail_panel.py`：指标条、结构化详情和品牌空状态；
- `unified_paper_orchestrator/ui/main_window.py`：响应式头部、产品导航、阶段动作、状态表达和空间分配；
- `tests/test_ui_visual_assets.py`：品牌资源、显示摘要、紧凑论文编号、样式与图标接线契约。
