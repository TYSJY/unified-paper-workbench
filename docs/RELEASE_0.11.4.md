# 0.11.4 发布记录

本版聚焦正式 Qt Quick 工作台的主要入口回归和投稿状态检查可见性。

- 逐项实测总览、工作区、设置、账号与站点、写作、图表与插图、选刊与作者、投稿中心、一键全流程及紧急停止入口。
- 英文及其他长文本语言在常见 Windows 高 DPI 宽度下提前切换为紧凑头部，避免按钮或工作区入口越界。
- 投稿中心常驻显示最近一次检查的完成时间、完成数量、失败数量和待处理数量。
- 投稿检查完成提示会根据实际结果显示成功、部分完成或失败，不再统一显示“操作完成”。
- 保留 0.11.3 正式 EXE、源码快照和运行状态快照作为可回退基线。
- 写作、图表、选刊作者和智能投稿的阶段内部提示词均未修改。
