# Unified Paper Orchestrator 0.10.17

## 重点变化

- 智能投稿在计划、立即巡检和定时巡检前，依据目标期刊、站点注册表、论文身份及历史投稿记录确定性核对站点绑定；可以自动纠正旧的投稿系统标识并恢复既有投稿编号。
- 已经完成外部投稿但仍保留旧路线的论文，可以安全交接到 Smart 监控路线；交接不会重新投稿，也不会绕过正在执行的队列或 Worker。
- Taylor & Francis 登录页、注册页和已登录后台采用更严格的页面识别，避免把登录页误判为注册成功或有效会话。
- 当期刊后台已有账号但本地没有可用密码时，论文继续保持“监控中”，并显示“保存既有账号密码后继续”的明确恢复动作；凭据问题不再被误报为投稿状态检查失败。
- 多邮箱批量检查与期刊后台回退使用独立通道。邮箱检查已经完成后，后台回退不会再次触发同一批 SDK 邮箱检查，从而减少重复 Turn 和 Token 消耗。
- 监控失败归一化会隔离错误自动注册或被站点拒绝的账号绑定，不再让错误凭据持续污染论文状态。

## 兼容与数据

- 没有修改写作、画图、选刊作者阶段及其内部提示词。
- 既有论文目录和投稿状态账本保持原位；纠正站点绑定前已建立独立状态备份，可按需回退。
- 账号密码仍由本机凭据层处理，不写入 SDK 提示词、普通状态文件或审计文本。

## 验证

- 覆盖站点纠正、旧投稿编号恢复、Smart 路线交接、Taylor & Francis 页面分类、凭据恢复状态、监控访问失败归一化及后台回退去重测试。
- 发布构建继续执行版本探测、命令行探测和 Windows EXE 启动探测。
