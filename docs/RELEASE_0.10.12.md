# Unified Paper Orchestrator 0.10.12

## 重点变化

- 智能投稿页顶部新增持久化的最近检查摘要，明确显示检查中、正常、发现新状态、部分完成或失败。
- 智能投稿论文表新增“状态检查”列，逐篇显示结果和最近检查时间。
- 支持直接区分正常、检查失败、后续处理失败、待修订稿、自动转投、自动修复、已自动处理和已录用。
- 点击“立即检查投稿状态”后立刻显示启动中的蓝色状态；检查结束后自动刷新为最终结果。
- 所有标识只读取现有投稿状态账本，不新增模型调用和 Token 消耗。
- 写作、画图和选刊作者阶段的内部提示词未修改。

## 回退

发布 0.10.12 前的 0.10.11 可执行文件保存在 `releases/0.10.11/UnifiedPaperOrchestrator.exe`。
