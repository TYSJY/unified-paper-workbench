# Unified Paper Orchestrator 0.10.0

## 智能投稿 SDK 浏览器执行

- 正常投稿网页操作迁移到本程序独立的 Codex SDK 运行时。
- 每篇论文固定绑定一个 SDK 会话；同一论文后续动作继续复用该会话。
- 排队、并发槽、候选选择和状态推进全部由程序控制，不再消耗 AI 调度 Token。
- 新任务可在已有任务运行时继续加入；一次运行会持续补充空闲槽，直到本次明确选择的队列处理完毕。
- 新增项目自有 MCP 浏览器服务，SDK 会话只看到当前论文的 10 个受限工具。
- 禁用投稿 SDK 会话中的 Apps、插件、通用浏览器、Computer Use、Shell 和图片生成工具。

## 浏览器能力与最终提交

- 支持限定站点来源内的页面列表、快照、导航、等待、文本填写、下拉选择、文件清单、文件上传和普通点击。
- 文件路径不再整体写入 Prompt；需要上传时先读取短文件 ID，减少 Token 并限制文件作用域。
- 页面快照不会返回密码输入值、Cookie 或浏览器存储。
- 普通点击硬性拒绝最终提交控件。
- 最终提交只能通过专用一次性工具执行：动作前领取 EXE 授权、只点击一次、随后捕获可信确认；结果不明确时禁止自动重试。

## UI 与可观测性

- 智能投稿支持明确多选启动，并按配置的并发上限运行。
- 状态区显示 SDK 运行/空闲、模型、固定会话数、论文 Turn、Token 和错误。
- 可直接查看所选论文的内部 SDK 会话记录；该会话位于程序独立 CODEX_HOME，不出现在 ChatGPT Codex 桌面任务列表。
- “查看调度状态”明确说明调度器是程序逻辑，因此不存在单独的 AI 调度会话。
- 旧可见 Worker 与旧调度提示词仍保留为兼容回退路径。
