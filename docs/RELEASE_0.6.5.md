# 0.6.5 历史画图任务一键迁移恢复

本版本修复画图实时任务表中“历史任务待重新排队”与“运行选中画图任务”互相矛盾的问题。

- `migration_review` 任务不再进入普通阶段准入判断。
- 点击“运行选中画图任务”时，程序先验收当前 Step 2 产物。
- Step 2 契约有效时保留已有 figure plan、逐图 prompts 和 briefs，直接从 Step 3 继续。
- Step 2 无效时才从 Step 2 重跑，不会盲目重做全部流程。
- 旧任务记录中的桌面 Codex 会话 ID 会保存为 `legacy_thread_id`，不会冒充当前 V2 活动会话。
- 新恢复请求进入当前隔离 V2 journal，并创建一个新的固定 SDK 会话；之后仍按一篇论文一个会话的规则运行。
- 没有修改任何写作、画图、选刊作者或投稿阶段内部 Prompt。

现场目标 `2026-07-02_005_io-residency-decoding` 的 Step 1、Step 2 均通过当前契约；恢复入口因此选择 Step 3。
