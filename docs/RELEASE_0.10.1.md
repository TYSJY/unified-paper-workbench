# Unified Paper Orchestrator 0.10.1

## 智能投稿候选自动发现

- 智能投稿页面只读扫描统一状态，自动显示选刊作者阶段已经完成、投稿包存在且尚未进入投稿执行的论文。
- 自动候选不写入智能投稿状态文件，不切换稳定投稿路线，不建立 SDK 会话，也不占用并发槽。
- 候选行明确显示“自动候选”“启用智能投稿”“未建立 SDK”和当前投稿路线。
- 单篇详情解释候选、启用、本地检查和在线启动之间的区别。

## 显式启用

- “导入并检查”现在会先明确切换到智能投稿试运行路线并登记任务，再执行本地预检；不会联网。
- “启动智能投稿”继续执行路线切换、本地预检和 SDK 在线入队。
- 右键候选可以选择“启用并启动智能投稿”或“仅启用智能投稿（不联网）”。
- 稳定投稿列表右键增加“启用智能投稿（仅登记，不联网）”，消除必须先进入一个不存在的智能投稿行才能切换路线的循环。
- 启用失败时会尝试恢复原投稿路线；任何在线行为仍需用户明确启动。

## 兼容性

- 保留 V1 的主按钮文案、初始安全提示、表格列标识和回调入口。
- 未修改写作、画图、选刊作者及智能投稿内部任务提示词。
