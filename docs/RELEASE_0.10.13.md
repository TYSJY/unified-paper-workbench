# Unified Paper Orchestrator 0.10.13

## 重点变化

- 修复彻底删除时递归扫描 SDK 任务产物与基线，导致并发批次中的无关论文任务被误清理的问题。
- 生命周期删除、运行中检查和存在性判断只按任务映射键或明确论文身份字段匹配，不再把产物路径中的论文编号视为任务归属。
- 右键归档和彻底删除固定作用于实际点击的论文；确认窗口明确显示准确数量和论文编号。
- 恢复 2026-07-18 批次中被误清理的 4 条写作 SDK 调度记录，已有产物和固定会话保持不变。
- 修复“账号与站点”窗口与智能投稿后台使用不同可信备份根目录的问题，可正常验证并打开已有账号库事务。
- 写作、画图和选刊作者阶段的内部提示词未修改。
