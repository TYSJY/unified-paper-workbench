# 0.5.1 发布记录：Codex 账号授权修复

## 修复结果

- 修复网页授权成功但 EXE 误报 `authorization_failed` 的问题。
- 登录完成后始终读取独立 `CODEX_HOME` 的实际账号状态，不再把 SDK 完成通知当作最终登录事实。
- 当授权文件已经更新但令牌受本机时钟偏差影响尚未生效时，最多等待 180 秒并重试账号读取。
- 真正失败且没有授权文件变化的登录不会进入长时间重试。
- 登录失败窗口改为显示稳定的内部错误码，不暴露令牌、授权地址或上游错误正文。

## 现场证据

现场 OAuth 回调校验与令牌交换均成功，账号凭据已写入 `state/codex_sdk_home/auth.json`；随后使用同一独立目录读取到 `authenticated=true`、`auth_mode=chatgpt`。本机 Windows 时间服务处于停止状态，本地时间约慢 94 秒，与新令牌的生效时间偏差一致。

## 不变项

- 不修改写论文、画图、选刊作者、投稿的任何内部 Prompt。
- 不覆盖 Codex Desktop 的登录目录。
- 不启动论文任务，也不改变现有八条写作队列。
- 写作仍由 0.5.0 引入的单一本地事件调度器和固定论文会话执行。
