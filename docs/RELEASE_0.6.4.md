# 0.6.4 画图动态调度与可配置流程

本版本把画图 V2 从“启动时固定一批任务”升级为程序拥有的动态工作队列，并让画图步骤与写作步骤采用一致的配置与快照思想。

- 运行期间新加入的论文会立即进入当前调度循环，并在空闲并发槽位出现时启动，不再等待旧批次全部结束。
- 并发许可覆盖一篇论文的完整流程；并发上限为 4 时，最多同时占用 4 篇论文的固定 SDK 会话，不会提前为整条积压队列创建会话。
- 每篇论文仍只绑定一个固定会话，论文内部步骤严格顺序执行；调度和步骤推进全部由程序逻辑完成，不调用 AI 充当调度器。
- “调度设置与提示词”增加“画图步骤”：默认 Step 1–3，新任务冻结当时的流程版本；可移除可选的参考研究 Step 1，也可在末尾增加、排序、删除自定义后处理步骤。
- 内置 Step 2 与 Step 3 形成最终交付依赖并受保护；自定义步骤必须继续维护完整提交包契约。
- 已完成任务再次排队时，只有源 TeX、前置产物、流程版本、提示词哈希和输出产物哈希全部一致，程序才跳过该 Step；任一输入变化都会正常重跑。
- UI 显示流程版本、动态步骤名称、固定会话和 Turn，并区分“暂停全部画图”与“暂停选中论文”；单篇任务可在原会话和原 Step 边界继续。
- 4 份既有画图内部 Prompt 未作任何修改，SHA-256 仍为 0.6.3 的封印值。

验证覆盖默认 Step 2→3 固定会话、论文间并发、运行中动态加入第二篇论文、指纹命中零 Turn 跳过、画图流程版本增删、自定义提示词保存、单篇暂停状态和旧三步任务兼容。
