# Unified Paper Orchestrator 0.10.2

本版本完成智能投稿账号登录与缺失账号注册链路的第一轮生产化，重点是让账号自动化可用，同时把密码隔离在模型边界之外。

## 主要变化

- 新增本机可信凭据代理。保存的账号密码由本机程序直接写入受控浏览器，不进入 Codex SDK、MCP、Prompt、状态文件、审计记录或 UI。
- 新增独立账号加密库，使用 Windows 当前用户 DPAPI；旧 Smart Submission 明文账号支持事务化、幂等迁移，并保留迁移前备份。
- 凭据解析器同时支持旧运行时 Vault 与新账号 Vault，损坏引用会失败关闭，不回退到残留明文。
- 自动为论文选择与投稿系统和目标域名匹配的账号；无匹配账号时可配置为自动注册、询问或阻塞。
- 新增 Springer Nature 站点适配器，明确限制 submission、IDP 与 profile 域名，支持邮箱页、密码页、注册页、登录后控制台和人工验证卡点。
- 验证码、2FA、邮箱验证、条款确认和密码失效均显示为可恢复状态；UI 提供“继续登录/验证”入口。
- 旧版 `SMART_SECRET_BROKER_REQUIRED` 阻塞会窄范围迁移回本地预检，不会误恢复当前验证码、2FA 或邮箱验证卡点。
- 修复 Springer 密码表单的敏感控件继承导致的验证码误判，以及页脚 Terms 链接导致的条款确认误判。
- 登录完成后的跨域重定向若短暂超出一次 CDP 操作，会在已认证控制台上自动补记签名会话证据。
- 智能投稿任务表新增登录/注册状态、账号绑定、模型会话和下一步提示；设置页可配置缺失账号策略和条款确认策略。
- 作者模板新增“作者贡献声明”，并贯穿 `author_info.md`、阶段元数据指纹和智能投稿安全载荷；Springer/SNAPP 缺失该事实时会在打开浏览器和启动 SDK Turn 前直接提示。
- 修复编号单位行（例如 `1. Institution:`）未被智能投稿识别的问题。补齐作者资料后再次点击“启动智能投稿”会自动重新预检并恢复原任务，无需删除或重新导入。
- 智能投稿页新增“作者资料”和“套用作者模板”入口，阻塞任务可在当前页面直接修复。

## 不变的安全边界

- Codex SDK 只在本机代理确认精确域名登录态后接管网页任务。
- SDK Worker 不能读取凭据库、密码、Cookie、令牌或一次性验证码。
- 普通浏览器工具不能点击最终投稿按钮。
- 最终投稿仍要求 EXE 生成一次性、精确尝试绑定的人工授权，并在提交后保存回执证据。
- 写作、画图和选刊作者阶段的既有内部提示词没有因本版本改动。

## 兼容与回退

- 旧账号记录保留原账号标识，仅将密码字段替换为加密引用。
- 迁移过程先提交加密记录，再清除旧明文；中断后可幂等重跑。
- 发布前保留代码快照与真实账号数据备份，可分别回退代码和迁移前账号状态。
