# 0.6.9 选刊与作者 V2 固定会话调度

本版本把“选刊与作者”阶段迁移到与写作、画图一致的程序调度架构，移除运行时对 AI 调度器会话和定时心跳的依赖。

- 每篇论文只绑定一个固定 Codex SDK 会话；现有 `02_03_choose_journal_and_make_package.md` 合并提示词只发送一次。
- 并发由程序控制，可设置 1～6 篇；同一篇论文不会重复占用并发槽或创建多个会话，运行期间新入队论文可直接进入空闲槽位。
- 每篇论文入队时冻结流程、模型、推理强度和 Token 上限；重试沿用该次请求的冻结配置，模型不可用时明确阻塞，不静默切换。
- 输入契约检查主 TeX、作者资料 READY 状态和元数据指纹；输出契约检查选刊结论、投稿包、作者可见主稿、残留标记及元数据指纹一致性。
- 已完整有效的投稿包可零 Turn 复用；`NEEDS_MINOR_FIX` 且仅缺编译 PDF 时按有效终态保留明确提醒，`READY_TO_SUBMIT` 缺 PDF 则拒绝通过。
- 选刊与作者页新增 V2 实时任务表，可查看当前状态、模型、Token、固定会话 ID、Turn 与验收卡点，并支持单篇暂停、继续和阻塞后重新排队。
- “调度设置与提示词 → 选刊作者步骤”可配置阶段默认与合并任务执行档案；配置不会修改提示词正文。
- 全局归档与彻底删除同步清理选刊作者 SDK journal 和对应的独立会话记录，避免任务从回收状态重新出现。

本版本没有修改写论文、画图、选刊作者或投稿阶段的内部提示词。选刊作者调度器及四份任务提示词均通过固定 SHA-256 校验确认字节未变。
