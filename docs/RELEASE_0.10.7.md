# Unified Paper Orchestrator 0.10.7

## 智能投稿本地化最终提交修复

- Springer Nature SNAPP 最终审核页支持识别“提交稿件”“最终提交”“确认提交”等中文最终提交标签。
- 最终提交校验统一优先使用用户可见标签，避免把登录页或普通表单中仅内部 id 含 `submit` 的按钮误判为最终投稿。
- 一次性最终提交授权改为在最终按钮完成语义校验后、实际点击前消费；校验失败不会再产生“授权已消费但实际未点击”的不明状态。
- 为 0.10.6 的本地化按钮遗留故障增加严格恢复路径：校验签名授权与三段审计链、匹配固定 SDK Turn、连续读取两次同一 `/review` 页面、确认唯一最终提交按钮仍可用且无成功证据后，才恢复为待提交。
- 未修改写作、画图、选刊作者或智能投稿阶段的内部提示词。
