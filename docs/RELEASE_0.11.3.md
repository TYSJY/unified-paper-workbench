# 0.11.3 发布记录

## 目标

在不修改写作、图表、选刊作者和智能投稿阶段内部提示词的前提下，使 Qt Quick 新版工作台具备旧生产路径仍然需要的完整操作能力，并完成可回退、可验证的正式 EXE 发布。

## 本版变化

- 恢复实时任务投影、后台错误可见性、单篇继续/暂停/重试、阶段批量运行和紧急停止。
- 一键全流程支持持久化续跑；首次启用 Step 5 自动信任时会在当前窗口完成密码确认，不再出现无输入入口的死路。
- 恢复写作数据关口、论文归档/回收站/彻底删除，以及图表、选刊作者和智能投稿的阶段操作。
- 恢复智能投稿启动、立即检查、人工接管、继续登录和安全转投入口。
- 工作区可以创建、注册、切换并自动重启；窄窗口也保留明确的工作区切换按钮。
- 设置中心支持阶段步骤、模型、推理强度、Token 上限、动态步骤、写作门禁、投稿监控和作者模板。
- 简体中文与英文目录保持完整同构；账号与投稿站点窗口继承当前语言和当前论文工作区。
- 现代输入框、下拉框、响应式按钮和状态信息完成视觉统一；旧经典控制台与旧稳定投稿入口不再暴露。
- 主 EXE、工作区重启和账号窗口均以无控制台方式启动。
