# Unified Paper Orchestrator 0.10.19

## 重点变化

- 智能投稿新增确定性投稿身份账本，保留当前和历史稿件编号、期刊路线、活跃/关闭状态及唯一主记录。
- 同一期刊路线出现多个活跃投稿编号时，程序显示“重复投稿待处理”，从队列移除该论文，并在调度、SDK 派发和最终提交三层禁止继续修改或创建新投稿。
- “需要作者操作”拆分为待核对要求、技术修改、科学返修、撤稿后转投及明确拒稿，不再统一显示成“处理返修”。模糊通知不会自动启动网页会话。
- 明确技术修改只作用于一个已核验的现有稿件编号；科学返修会等待新的修订稿包，不上传原包。
- 明确拒稿后由程序自动关闭旧投稿身份，调用选刊作者 V2 SDK Step 2–3，验收新投稿包后重新进入智能投稿。若通知要求先撤稿，则旧投稿关闭前禁止生成新投稿。
- Gmail 和学校邮箱状态检查同时匹配唯一主编号、其他活跃编号及已关闭历史编号，避免旧编号邮件漏检。
- UI 新增唯一主投稿编号、活跃编号、重复编号和身份状态，并分别显示“技术修改”“待核对修改要求”“科学返修”“正在撤回后转投”“自动转投”。
