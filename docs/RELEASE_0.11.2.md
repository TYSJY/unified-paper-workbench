# 0.11.2 发布记录

## 英文与多语言布局修复

- 顶部“刷新”“一键全流程”“账号与站点”和“紧急停止”改为按翻译文本实际宽度自动计算，不再使用只适合中文的固定按钮宽度。
- 非中文语言在较窄窗口下更早进入紧凑头部：保留主动作文字，次要动作使用图标，并通过悬停提示和无障碍名称显示完整含义。
- 通用按钮在极端布局约束下会在按钮边界内省略，并显示完整悬停提示，不再把文字绘制到按钮外部。
- 语言选择器宽度随当前语言名称扩展，为后续增加繁体中文、日语等目录保留空间。
- 已在 1540×900 与 1100×760 的真实 Windows 窗口中检查总览、写作和智能投稿页面。

## 发布与恢复

- 版本升级到 0.11.2，并同步 Windows `FileVersion` 与 `ProductVersion`。
- 0.11.1 正式 EXE 保存在 `releases/binaries/0.11.1/`。
- 改动前 UI 与构建配置保存在 `releases/source-backups/0.11.1-english-layout-prechange-20260723/`。
- 本次只修改 Qt Quick 呈现层、测试和发布元数据；没有改动阶段提示词、调度器、论文状态或投稿逻辑。
