# Unified Paper Orchestrator 0.10.10

## 智能投稿监控

- 新增主界面“立即检查投稿状态”和设置页“立即检查一次”。
- 手动立即检查会明确确认范围，并通过固定 Codex SDK 会话只读检查已投稿论文。
- 每日检查时间仍可使用本机 `HH:MM` 自定义。
- 打包版保存时间时会同步注册 Windows 本机计划任务；主窗口打开时另有 15 秒一次的到点与当日补跑检查。
- Windows 计划任务、程序内定时器和旧 Codex 自动化共用跨进程执行权，同一天的自动巡检只会启动一次。
- 状态界面新增本机任务注册状态、上次开始/结束时间、触发来源、结果和检查论文数量。
- 暂停智能投稿会同时暂停每日监控并禁用本机计划任务。

写作、画图、选刊作者阶段的内部提示词均未修改。
