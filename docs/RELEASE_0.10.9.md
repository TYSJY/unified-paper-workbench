# Unified Paper Orchestrator 0.10.9

## 智能投稿定时巡检与自定义时间

- “智能投稿设置 → 运行概况”新增每日检查时间，支持 `HH:MM` 本机时间，例如 `09:00`、`21:30`。
- 默认时间仍为每天 `09:00`；已有旧版小时配置会自动迁移，暂停、恢复和临时快速唤醒结束后都回到用户保存的时间。
- 每日唤醒不再让 AI 判断论文、队列或并发槽，只运行一个确定性的本地触发命令；程序区分手动快速唤醒和每日巡检，再调用固定 Codex SDK 会话。
- 已投稿论文到点后进入一次只读状态巡检；巡检会话禁止上传、替换稿件、撤稿、重投或再次点击最终提交。
- 同一论文每个本地日期最多自动检查一次；界面显示检查是否排队、上次巡检时间和上次结果。
- 巡检结果支持 `monitoring`、`revision_needed`、`retarget_needed`、`rejected`、`accepted` 等状态，并写回权威任务账本；拒稿会进入待换投状态。
- 修复已有投稿证据覆盖返修/换投状态的问题：明确的返修或换投状态现在优先于旧投稿回执。
- 写作、画图和选刊作者阶段的内部提示词未修改。
