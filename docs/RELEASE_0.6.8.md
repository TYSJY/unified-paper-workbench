# 0.6.8 论文全局归档与彻底删除

本版本把论文视为跨写作、画图、选刊作者和投稿阶段的全局对象，修复“某一阶段移入回收站后，V2 实时任务、写论文页和总览仍然显示”的问题。

- 总览、四个阶段列表、写作/画图实时任务表和智能投稿列表均提供右键“归档（所有阶段）”与“彻底删除（所有阶段及文件）”。
- 归档会从所有活动页面移除论文，取消待执行队列与命令，清理写作/画图 V2 SDK journal、旧写作 dispatch 和智能投稿状态，并保存可恢复的状态快照。
- 写作 idea、refs、论文与实验数据，画图产物，选刊作者/投稿目录，旧阶段回收区副本以及对应的独立 SDK 会话日志会一并进入全局归档区。
- 彻底删除会清理活动目录、旧 `state/deleted`、全局归档副本和对应任务状态；持久审计只保留论文编号的 SHA-256，不保留明文编号。
- 正在执行的 SDK/在线投稿任务不会被中途粉碎删除；界面会要求先暂停并等待当前 Step 结束，避免运行线程在删除后重新生成任务记录。
- 统一状态新增归档索引。即使旧控制器残留历史记录，已归档论文也不会重新出现在总览或阶段列表。

本版本没有修改写论文、画图、选刊作者和投稿阶段内部提示词。
