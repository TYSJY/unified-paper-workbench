# Unified Paper Orchestrator 0.10.8

## 智能投稿成功回执对账修复

- Springer Nature SNAPP 的 `/success`、`/confirm`、`/submitted`、`/complete` 和 `/thank` 终态页面不再参与“打开的远程草稿”发现，避免成功页改变已经冻结的一次性授权绑定。
- `submitted`、`monitoring` 和 `accepted` 结果在落盘前不再刷新远程草稿绑定。
- 当最终提交后的 SDK Worker 错误报告 `blocked`，但程序已经保存同一论文、路由、尝试、固定会话和一次性授权对应的签名成功回执时，可信回执优先于后到的错误状态。
- 新增严格的成功回执恢复：必须同时通过已消费授权审计链、不可变成功证据文件、唯一匹配的在线成功页、页面加载完成、成功语义和“最终提交按钮不存在”检查；恢复过程没有点击入口。
- 恢复后统一状态投影同步为 `submitted / monitoring`，保留确认地址与证据文件，并进入邮件优先监控。
- 新增回归测试，覆盖终态结果不刷新草稿绑定以及成功后误阻塞的无点击恢复。
- 未修改写作、画图、选刊作者或智能投稿阶段的任何内部提示词。
