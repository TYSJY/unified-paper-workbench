# 0.6.1 动态写作流程与自动阶段准入

本版本把“流程有多少步”和“论文何时进入下一阶段”从界面人工交接改为可审计的程序规则。

- “调度设置与提示词”新增写作步骤配置页。默认仍为原来的 Step 1–10，可在连续内置步骤尾部增加自定义步骤，也可从选中的内置步骤起截短流程。
- 每次配置变更都会生成独立版本；每篇新论文在创建时冻结完整流程快照，运行中的论文不会被后续增删步骤影响。
- 写作调度、进度、完成标记、产物契约和最终清理门禁均使用论文自己的动态终点，不再把 10 写死在程序逻辑中。
- 自定义步骤必须先保存 Prompt 才能用于新任务；保存后生成 SHA-256 绑定的不可变文件，旧论文继续引用旧版本。
- 10 份既有写作 Prompt 保持原字节不变，内置 Prompt 在界面中只读，未改动阶段内部提示词。
- 写作严格完成后自动准入画图阶段；画图严格完成后自动准入选刊作者阶段；选刊作者严格完成后自动准入投稿阶段。
- 阶段页只显示本阶段已经准入的论文。下游遗留目录或文件不再反向伪造上游“完成”。
- 保留右键人工越级入口，用于用户决定提前结束流程或处理历史例外；越级原因、时间和当时上游状态会写入审计。
- “运行全部本阶段任务”会先扫描并加入所有已准入、可执行的论文，再启动本阶段执行器；统一状态变化会由界面定时自动刷新。
- 切换投稿执行路径时会同步重算阶段准入、当前阶段和下一步动作，避免保存后一瞬间显示旧状态。

唯一用户入口仍为 `dist/UnifiedPaperOrchestrator.exe`。
