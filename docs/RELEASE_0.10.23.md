# 0.10.23：专业工作台与信息架构治理

发布日期：2026-07-21

## 本版目标

本版在 0.10.22 的异步刷新、统一主题和一键全流程基础上，针对真实工作区和 1024×720 笔记本窗口，系统治理五个阶段的界面信息密度、操作层级、状态视觉和详情结构。没有另建新前端或 V3，也没有修改内部提示词、业务状态机、SDK 调度、产物契约或论文数据。

长期 UI 规则已固化到：

- `docs/UI_DESIGN_SYSTEM_AND_INFORMATION_ARCHITECTURE_2026-07-20.md`

## 主要变化

### 统一信息层级

- 总览、写作、画图、选刊作者、稳定投稿和智能投稿统一为“操作—当前任务—全部论文—结构化详情—技术层”；
- 默认只展示状态、下一步、卡点、进度和最近事件；
- SDK 会话、Turn、模型、Token、执行器、队列和原始日志改为按需显示；
- 论文详情从原始日志升级为结构化卡片，窄侧栏标题自动换行。

### 状态视觉与字号密度

- 默认字体、辅助字体、表格行高、卡片、按钮和页签由统一主题管理；
- 普通和已完成论文恢复白色背景，成功状态使用 Badge 或文字；
- 整行浅色只保留给阻塞、失败、排队和人工越级；
- 不再出现十几行连续绿色导致状态重点丢失的情况。

### 操作层级与作用域

- 每个阶段保留一个明确的选中论文主动作；
- 阶段批量运行和暂停收进“运行与暂停”；
- 越级、重跑、归档、彻底删除、打开产物和技术诊断收进“更多操作”或右键菜单；
- 没有选择论文时，上下文按钮禁用并直接解释原因；
- 智能投稿的第三个动作会根据论文状态切换为“修改完成并继续”“转投其他期刊”或“人工修改当前页面”。

### 响应式空间分配

- 全局头部、工作区栏和阶段操作区按窗口宽度自动换行；
- 1024×720 下，阶段当前任务默认显示摘要，表格可手动展开；
- 智能投稿运行概览在低高度窗口默认折叠，仍可手动展开；
- 小屏默认能同时看到多篇任务、论文列表和右侧下一步；
- 总览和各阶段的搜索使用防抖，阶段筛选只重绘当前页面。

### 共享组件与性能

- 新增响应式 `MetricStrip`；
- 新增带技术层切换的 `StructuredDetailPanel`；
- 详情渲染使用签名缓存，避免无变化重绘；
- Treeview 继续使用增量同步，保留选择、焦点和滚动位置；
- 当前任务预览不再重复已经完成的历史任务。

## 兼容性说明

- 写作证据按钮保留熟悉的“导入真实实验证据…”和“数据已手动改完并继续”；
