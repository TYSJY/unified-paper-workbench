# Unified Paper Orchestrator 0.10.20

## 重点变化

- 智能投稿页新增“转投其他期刊”入口，可选择“指定具体期刊”或“AI 智能选刊”。
- AI 选刊可配置 SCI/SCIE、中文核心或普刊，并可选择中稿优先、速度优先、质量优先或均衡策略；SCI 路线继续支持分区、OA、APC、关键词和特刊偏好。
- 转投请求、撤稿策略和运行状态写入独立的确定性状态模型，不再交给 AI 调度器判断下一篇论文或下一步动作。
- 程序先读取投稿身份账本：明确拒稿、已撤稿、已关闭或明确失效的转投邀请可跳过撤稿；仍有活动稿件时进入受限网页会话，只允许核验并撤回请求中列出的精确投稿编号。
- 日期或截止时间本身不再作为“已经撤稿”的证据；全部旧稿编号得到明确关闭证据前，程序禁止新选刊包进入在线投稿。
- 指定期刊会写入每篇论文的选刊偏好并作为强约束；选刊作者 V2 完成后，程序再次比较实际目标期刊，名称不一致时阻止继续投稿。
- 新投稿包继续复用选刊作者 V2 SDK Step 2–3 和既有产物契约；验收通过后自动回到智能投稿的本地预检、在线提交和状态监控链路。
- UI 会显示转投方式、目标范围、优先级、撤稿策略、待核验编号和当前转投状态。
