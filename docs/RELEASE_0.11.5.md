# 0.11.5 发布记录

## 目标

消除一键全流程启动时，Qt 工作台状态轮询与批次账本写入之间的瞬时锁竞争，并确保启动末段失败后重试不会重复创建论文。

## 修复

- 全流程状态读取直接读取原子提交快照，不再占用写锁。
- 全流程账本写入对瞬时跨进程锁竞争执行有界重试。
- 若批次已创建两条写作命令、但尚未登记槽位，再次以相同并发量启动时会恢复该批次和原命令。
- 恢复时重新应用阶段并发上限与智能投稿策略，并唤醒原写作 SDK 任务。

## 验证

- 新增原子无锁读取、瞬时锁重试和失败启动原命令恢复测试。
- 全仓测试、正式 EXE 打包及 CLI 探针均需通过后才发布。
- 写作、图表、选刊作者和智能投稿阶段内部提示词未修改。
