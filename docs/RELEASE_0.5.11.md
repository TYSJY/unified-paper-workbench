# 0.5.11 中间稿延迟清理与 SDK 会话可视化

- 实验数据门禁确认后，Step 6–9 的显式验证/占位清理标记记录为 `latex_forbidden_marker_deferred` 警告，不再阻断；Step 10 最终稿继续严格拒绝任何残留。
- 旧规则已经拦下的 Step 6–9，如果原固定会话、Turn、终态标记和当前产物均可验证，控制器会本地认定该 Step 完成并推进下一步，不创建新模型回合。
- SDK 实时任务表直接显示固定会话 ID；详情显示当前/最近 Turn、内部 SDK/CLI 执行方式、真实错误说明、验收文件以及非阻塞清理警告。
- 新增 SDK 会话查看窗口，可阅读本程序独立 `CODEX_HOME` 中的用户/调度器与 Codex 消息，也可打开原始 JSONL。
- `paper_blocked`、等待、暂停和重新排队事件现在都会刷新统一状态投影，避免实时表与下方论文表状态不一致。
- 总览执行方式改为明确说明“写作 V2 SDK、其余阶段 V1 兼容”，写作实时摘要显示实际 SDK 认证方式。
- 20 份用户调优阶段 Prompt 文件保持原字节不变。
